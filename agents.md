# AGENTS.md

This file contains the canonical development instructions for every AI coding
assistant used in this repository.

## Goal

Produce clean, maintainable, production-quality code.

When making changes:

- Preserve existing architecture.
- Prefer readability over cleverness.
- Never break existing functionality.
- Explain major design decisions.

---

# Coding Style

## HTML

- Semantic HTML only.
- Proper indentation.
- No inline styles unless requested.

## JavaScript

- ES6+
- No one-line functions.
- Separate logic into reusable functions.
- Main program at bottom.

---

# General Rules

Always:

- keep functions small
- avoid duplicated code
- comment complex logic
- preserve accessibility
- preserve responsiveness

Never:

- invent APIs
- remove features without permission
- silently change behavior

---

# Before Finishing

Verify:

- no syntax errors
- formatting is consistent
- code runs
- requirements are satisfied

If uncertain, explain assumptions.
